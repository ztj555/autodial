# 提交前检查清单

> 一条条打勾，避免"提交后才发现"的返工。

---

## 一、包本身（最容易出错，先查这 5 条）

- [ ] 用的是本目录的 `extension/`，**不是**原目录 `AutoDial-Extension/`
- [ ] 打包后 **`manifest.json` 位于 zip 的根目录**，没有多套一层文件夹
      （套了文件夹商店会直接拒，这是最常见的低级错误）
- [ ] zip 里**没有** `README.md` / `AutoDial-API.md` / `create-icons.ps1`
- [ ] zip 里**没有** `提交材料/`、`说明.md`、任何 `.devdata` 之类的本地数据
- [ ] `manifest.json` 里 `"version": "6.4.0"`，且**比上一次提交的版本号大**
      （以后每次发版都必须递增，否则浏览器不更新且不报错）

自检命令：
```bash
unzip -l dist/AutoDial-6.4.0.zip | head -30      # 根目录应是 manifest.json，共 20 个文件
unzip -p dist/AutoDial-6.4.0.zip manifest.json | head -5
```

## 二、开发者账号（5 个坑，很多人卡几天）

- [ ] 已用 Microsoft 账号加入 Partner Center 的 Edge 计划（**免费**，不收注册费）
- [ ] 🔴 **登录用的微软账号，官方定义的 MSA 是 `@outlook.com` / `@live.com` / `@hotmail.com`**
      微软官方文档把 MSA 直接定义为「An Outlook.com, Live.com, or Hotmail.com account」。
      用 QQ / 163 / Gmail 注册的微软账号属于**非标准**情形 —— 但注意：这**不一定是**被拦的原因
      （有纯 Outlook 账号同样被拦的公开案例），只把它当作一个值得排除的变量。
      👉 若注册已被拦，**推荐改走「GitHub 登录」**（官方支持，微软会自动创建标准 MSA 并绑定）。
      （表单里那个「联系人邮箱」是另一回事，随你填）
- [ ] **「州/省份」是下拉框，直接选「浙江」**（不用手打）
      ℹ️ 网上流传「必须填大写代码 `ZJ`」—— 已逐字核对微软官方注册文档，**里面没有这条要求**。
      那只在「下拉加载不出来、只能手打」的异常情况下才会遇到。判定办法：点「验证地址」能过就没问题；
      若报错、或点完表单被重置，再把这一格改成 `ZJ` 重试（浙 `ZJ`、沪 `SH`、京 `BJ`、粤 `GD`）。
- [ ] **地址与邮编**：地址行1 `上城区望江东路`、地址线2 `望江国际3号楼`、城市 `杭州`、
      邮政编码 **`310016`**（望江街道一带的正确邮编；`310000` 是杭州的泛指码，偏泛）
- [ ] **地址填完先点「验证地址」** —— 「接受并继续」按钮在验证前是灰的、点不动
- [ ] ⚠️ **账户类型建议选「个人 / Individual」** —— 验证只需几小时；选「公司」要几天到几周，
      还可能接到微软验证合作伙伴的电话。**注册后账户类型和国家/地区都不能再改。**
- [ ] 🔴 **发布者显示名已最终确定**（会公开显示在扩展页面上，≤50 字符）
      **注册后极难改**：改它会触发重新验证（几天到几周），要改需联系微软支持，官方帮助文档甚至写「可能需要创建新帐户」。
      ⚠️ 别用 GitHub 用户名这类随手起的名字 —— 20 位坐席在商店页面上看到的就是它。
      **点「接受并继续」之前定死。**
- [ ] 🔴 **注册被拦时，已按 `06-注册被封锁-处置与申诉.md` 处置**
      症状：点「接受并继续」跳到 `…/error/msedgeaddons/SessionValidationFailed`，
      显示「你的请求被封锁」+ 参考编号 `715-123225`。
      **这不是表单填错**（2026 年 7 月起全球开发者都在撞，编号都一样）。处置顺序：
      手机热点 → 关掉 VPN/代理/安全软件 → 无痕窗口 + 官方深链**各只试一次** →
      仍失败就把 HAR 发到 `ext_dev_support@microsoft.com`
      （**Partner Center 里开不出工单**，因为没有 workspace）。
      **每失败一次截一张图**，把「相关性 ID」存下来。
